Sobre o Projeto

O RealMify é uma plataforma de estudos gamificada desenvolvida para transformar o processo de aprendizagem em uma experiência mais interativa e motivadora.

A aplicação utiliza elementos de gamificação para acompanhar o progresso do usuário, permitindo organizar estudos, tarefas e conteúdos enquanto o usuário evolui dentro do seu próprio reino.

O projeto foi desenvolvido utilizando Python e Django no back-end, SQLite como banco de dados, além de HTML, CSS e JavaScript no front-end.
