Sobre o Projeto

O Makeup Bell é uma loja virtual de maquiagem desenvolvida como projeto Front-End, com foco em criar uma experiência visual moderna, elegante e intuitiva para apresentação de produtos.

A aplicação permite navegar pelo catálogo, explorar diferentes categorias, pesquisar produtos, utilizar filtros e adicionar itens ao carrinho de compras de forma interativa.

O projeto foi desenvolvido utilizando HTML5, CSS3 e JavaScript, com foco na construção da interface, responsividade, organização dos componentes e interatividade da aplicação.

Destaques

  • Categorias de Maquiagem
  • Sistema de Busca
  • Filtros de Produtos
  • Carrinho Interativo
  • Adicionar e Remover Produtos
  • Cálculo do Total
  • Interface Responsiva
  • Design Feminino e Moderno
  • Interatividade com JavaScript
